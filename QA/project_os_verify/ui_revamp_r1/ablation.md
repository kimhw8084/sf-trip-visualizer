# Controlled ablation record

Material surfaces were reviewed against the six task oracles.

| Surface | Decision | Rationale |
|---|---|---|
| Date ribbon, map schedule strip | Removed | Day owns date and daily execution; one date select now drives the map and plan. |
| Desktop/mobile duplicate provider controls | Removed | One map-presentation control group adapts responsively. |
| Route codes as front door | Replaced | Human promise/recommendation leads; A1/A2/B1/B2 remain visible for expert comparison. |
| Four equally loud map routes | Subordinated | Primary route is emphasized; alternatives remain discoverable through patterns, labels, compare, and route hit layers. |
| Marker callout + preview + map-focus card + full Details duplication | Replaced | One Peek and one Place Inspector preserve the information path and return context. |
| Non-spatial schedule items | Kept as plan cards | Recovery and operational truth must not be forced into fake coordinates. |
| Route score profile | Kept compactly | Supports expert comparison without becoming a dashboard or sole recommendation oracle. |
| Map legend | Kept and compressed | Route patterns/typed geometry need explicit explanation; it is localized to the map owner. |
| Artificial full-screen splash delay | Removed | Local decision content and shell render as soon as canonical data is available. |
| Persistent full mini-detail on the map | Removed | Prevents simultaneous overlay competition and preserves map as spatial anchor. |

The remaining “kept” surfaces have a demonstrated task or truth role. No ablation claim is an E2 aesthetic/usability self-certification; Project OS remains the independent visual reviewer.
